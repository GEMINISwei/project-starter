# 0002. 網頁不開註冊，超級管理者只能用指令建立

狀態：採用（2026-10-25）

## 背景

建立第一個管理者的常見做法（設定精靈、環境變數帶帳密、註冊代碼）都會在網頁上留下建立高權限帳號的入口，
或一組要保管的秘密。

## 決定

- 超級管理者只能用 `make db superuser` 建立，包括第一個、之後新增的與失聯時的救援。
- 網頁沒有註冊入口，其餘帳號由超管在後台建立。
- 後台只開放給超管；角色權限只用在一般帳號的業務功能。

## 後果

- 能建超管的前提是握有主機 shell，不用保管註冊代碼。
- 沒有 email，忘記密碼只能請超管重設。
- 需要自助註冊或後台分權時要自己開發，連同 email 驗證、防機器人與限流。

現在的行為見 [帳號、角色與密碼](../features/accounts-roles.md)。
