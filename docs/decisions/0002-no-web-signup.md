# 0002. 網頁不開註冊，超級管理者只能用指令建立

狀態：採用（2026-10-25）

## 背景

第一個管理者帳號常見的做法有：首次開啟時的設定精靈、環境變數帶入的初始帳密、或用註冊代碼開放註冊。
這些都會在網頁上留下一個「能建立高權限帳號」的入口，或是一組要保管的秘密。

## 決定

- 超級管理者只能用 `make db superuser` 建立，包括第一個、之後新增的，以及全部失聯時的救援。
- 網頁上沒有註冊入口，其餘帳號由超級管理者在後台建立。
- 後台只開放給超級管理者，角色上的權限只用在一般帳號的業務功能，沒有任何權限能打開後台。

## 後果

- 能建立超管的前提是握有主機的 shell，不需要額外保管註冊代碼。
- 忘記密碼只能請超管重設，因為模板沒有 email。
- 需要自助註冊或把後台分權的專案要自己開發，並一起處理 Email 驗證、防機器人與限流。

現在的行為見 [帳號、角色與密碼](../features/accounts-roles.md)。
